使用说明 / 兼容性

1. 浏览器需支持 Web Bluetooth：桌面版与 Android 版的 Chrome、Edge 等 Chromium 内核浏览器均可使用。

⚠️ iOS / iPadOS 全都不支持（重要）：苹果强制 iPhone / iPad 上的所有浏览器（Safari、Chrome、Edge、Firefox…）共用 WebKit 内核，而 WebKit 至今未实现 Web Bluetooth，因此在 iPad / iPhone 上无法直接打开本网页连接设备，换浏览器无效。可行的替代方案：
① 改用 安卓平板或电脑的 Chrome / Edge（零改动，原生支持）；
② 用 ESP32 等做一个 BLE→WiFi 网关，由网关连接 RexForce 并通过 WebSocket 转发，网页改连局域网 WebSocket（仍是纯网页，无需上架）；
③ 用 Capacitor 把本页打包为 iOS 原生 App（蓝牙插件底层调用 CoreBluetooth，需 Mac + 苹果开发者账号）；
④ 改用微信小程序：设备官方已提供「体能训练追踪Lab」，或用 wx 蓝牙 API 自行移植。

2. 本页必须通过安全上下文打开：https:// 或 localhost。直接双击 file:// 在部分浏览器可能被拦截，建议用本地服务器（如 python -m http.server）或部署到 HTTPS 站点。

3. 点击「连接设备」后在系统弹窗中选择 Force-XXXX 设备；连接后设备立即推送数据，LED 转为常亮。

4. 协议：服务 0000FFE5…，TX(Notify) 0000FFE4…，RX(Write) 0000FFE9…；每帧固定 244 字节，单帧含 80 点（单机）或 40 组（双机），每点 3 字节含校验和，校验失败自动丢弃。

5. 建议连接后设备 MTU ≥ 244（默认 400）。
